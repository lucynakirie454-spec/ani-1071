Tailles :
```

Sans héritage virtuel :
Entite = 16 octets
Mobile = 32 octets

Dans cette version, Ennemi contient deux sous-objets Entite distincts.
Chaque sous-objet possède sa propre position, ce qui duplique les données.
```

Avec héritage virtuel :
```

Mobile = 40 octets

L'héritage virtuel ajoute des informations internes permettant de retrouver
la base virtuelle commune.
```

Deux positions :

Sans héritage virtuel :
```
Après e.Mobile::position.x = 3.0, la référence Mobile& voit x = 3.0 alors
que la référence Visible& accède à une autre position. Les deux références
pointent donc vers deux sous-objets Entite différents.
```

Avec héritage virtuel :
```
Après e.position.x = 3.0, la référence Mobile& voit x = 3.0 et la référence
Visible& voit également x = 3.0. Les deux références accèdent à la même
position partagée.
```

Pourquoi jamais :
```

Le diamant crée des ambiguïtés lors de l'accès aux membres hérités.
L'héritage virtuel résout le problème mais ajoute du coût mémoire et de la complexité.
La composition est généralement plus simple, plus claire et plus facile à maintenir.
```
